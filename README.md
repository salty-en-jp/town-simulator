# ツナグマチ

交通をつなぎ、お金を稼ぎ、街を育てる経営 × 都市発展シミュレーション。
PC と スマホ（iPhone）のブラウザで遊べます。いまは **試作版 v0.9.7** です。

- 遊ぶ: https://salty-en-jp.github.io/town-simulator/ （`main` ブランチに入ると自動で公開されます）
- 企画書: [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md)
- OpenTTD 仕組みリサーチ（操作感の参考）: [docs/OPENTTD_RESEARCH.md](docs/OPENTTD_RESEARCH.md)
- スマホ対応の検討: [docs/MOBILE_SUPPORT.md](docs/MOBILE_SUPPORT.md)

## 試作版でできること

- 12種類の貨物と11種類の産業（マップは64〜128マス四方、町3〜6つ。地形は いろいろ・山がち・平野・海沿い）
  - 森 → 製材所 → **木材**（村・町に家・アパート。都市は受け入れない）
  - 名産の工房 → **名産品**（町・都市へ。遠くの大きな町ほど高い。運ぶと町の評判が上がり観光客が増える）
  - 農場・牧場・漁港 → 食品工場 → **食料品**（町が早く育つ。穀物・家畜・魚のどれか1つでよい）
  - 鉄鉱山＋炭鉱 → 製鉄所 → **鋼材**（材料が2つそろうとフル生産）
  - 木材＋鋼材 → 建材工場 → **建設資材**（町に高層ビル）
- **届け先を指令で選べる**（受け入れ先が複数あるとき）、**相場表**（どこが高く買うか）
- **産業の持ち主**：自社・地元・他社。他社の産業は**権利を買う**か**輸送契約**を結ぶと運べる。自社の産業は毎月利益が入り、増産もできる
- **産業をつくる**：一次産業の**探鉱**（成功・失敗あり）、**工場の建設**。一次産業はときどき自然に見つかる
- **グラフ**：列車・路線の利益、産業の生産と運び出し、会社の収支と車両の資産価値（減価償却）
- **産業の稼働状況**の表示、**駅に止まる列車の一覧と行き先の差し替え**、**荷降ろしの振り分け**
- 駅・列車・町・産業の**名前を変える**、指令の**並べ替え**（↑↓・ドラッグ）
- **機関車だけの交換**（個別・同じ指令の列車まとめて・同じ機関車の列車まとめて）
- 駅を建てる前に、**集められるもの・受け入れる貨物をプレビュー**
- **イベント**：人口1,000人からの町で時々火事が起きる（プレイヤーの持ち物には影響しない。そのあと復興需要）
- **町の段階**：村（〜999人）→ 町（1,000人〜）→ 都市（5,000人〜）。都市は建設資材だけを受け入れる。成長はゆっくり
- **都市間の旅客**：大きな町どうしを結ぶほど旅客の運賃が上がる（1万人の都市どうしで ×2.5）
- **航路**：港（5億円）・空港（8億円）を買い取ると、自社の航路・空路を開いて船・飛行機を入れられる。鉄道で集めた貨物・旅客のうち航路で運べる分は運賃も入る
- **港と空港**（取引先）：港はどんな貨物も輸出として買い取り（海外の相場）、石油を出す。石油は化学工場で日用品になり、町・都市が欲しがる。空港は1970年から都市のそばにでき、旅客を高い運賃で受け入れる
- **ツナグ社の車両部門の買収**：わが社はツナグ社の鉄道部門を買い取ってできた会社。1972年ごろ車両部門が売りに出され、買い取ると自社開発がはじまる
- **自社開発**：動力（蒸気・ディーゼル・電気）×用途（通勤・特急・貨物・山岳・観光）と予算を選んで機関車を開発。試運転・高速試験で方針（堅実・挑戦・大胆）を選ぶ。相性は図鑑の相性表に記録
- **販売**：完成した機関車を8年ほどほかの鉄道会社に売る。評価・評判・時代の流行・自社の路線での宣伝・値段で売れ方が変わる。他社からの注文と、毎年の鉄道車両大賞
- **技術点と部品**：運行で技術点がたまり、部品（高圧ボイラー・液体変速機・回生ブレーキ・試験設備・量産ラインなど12種）を研究すると、それからの開発がずっと強くなる
- **電化**：1965年から、線路をなぞって架線を張れる（1マス40万円・岩場は2.5倍）。電気の車両は電化した線路だけを走る（今ある車両は電化なしでも走る）
- **車両図鑑**：全部の車両の絵・能力・説明文。使った車両を端末全体で集める（説明文は `src/data/zukan.md`）
- **新しいゲームの設定**：マップの広さ（町3・4・6つ）と時間の流れ（ゆったり・ふつう・目まぐるしい）
- **チャレンジモード**：ステージ8つ・今日のステージ・ランダムステージ。失敗なし、★1〜3
- **会社のランクと実績**（村の鉄道 → … → 日本を結ぶ鉄道、実績24個）
- **年代で登場する新型車両**（田舎向けから順に）、機関車ごとの両数の上限と「客車だけ／貨車だけ」の決まり
- **相場とブーム**：相場が毎月上下し、建設ラッシュ・材料不足・観光ブーム・復興需要で期間限定の高値
- 一覧の**並べ替え・絞り込み**、町の**人口グラフ**、はじめの目標の続きの「**次の目標**」
- 線路・駅・車庫の建設、解体、元に戻す
- 列車の購入（機関車＋客車／原木車／木材車）、クローン、売却
- 指令（行き先・積み込み・荷降ろし・スキップ・指令の共有）
- 町の成長（使われている駅の数、届いた木材で家が建つ）、駅の評価、産業の生産量の変化
- 財務（借入・返済・年間の収支・車庫代）
- **セーブ**：オートセーブ（前の日の分も2世代残る）、手動3枠、ファイルの書き出し・読み込み、タイトル画面の「続きから」、セーブ画面の「データの安全」
- **ホーム画面アプリ**：ホーム画面に追加するとデータが消えにくく、電波がなくても起動できる（サービスワーカー）
- **車庫の留置線**：車両を外して置いておく・別の列車につなぐ・選んで売る
- **依頼ボード**：達成するとお金がもらえる（ときどき新型車両を一足早く使える）
- 1マスの駅の向きの切り替え
- ゲームの中で読める**取扱説明書**と**リリースノート**（「？」ボタン）、**お知らせの履歴**、オートセーブの「保存しました」

まだないもの：信号・橋とトンネルのツール（川の上に線路を引くと自動で橋になります）・地形の変更。
列車どうしはぶつかりません（信号・衝突・複線は、プレイしてバランスを見てから決めます）。

## 操作

| | PC（OpenTTD と同じ） | スマホ |
|---|---|---|
| 地図を動かす | 右ドラッグ | 1本指ドラッグ（ツール選択中は2本指） |
| ズーム | ホイール、`+` `-` | ピンチ |
| 建設 | ツールを選んで左ドラッグ | ドラッグ（またはタップ2回）→ ✓ で確定 |
| 撤去 | Ctrl＋ドラッグ | 「撤去」ボタン |
| 見積もり | Shift＋建設 | 確定前にいつも表示 |
| 情報を見る | クリック | タップ ／ 長押し |
| 元に戻す | Ctrl+Z | 「戻す」ボタン |

キー：`Shift+F7` 鉄道建設、`A` 線路、`6` 解体、`7` 車庫、`9` 駅、`O` 駅の向き、`R` 撤去切替、`D` 解体、`Esc` 解除、
`F1` 一時停止、`F3` セーブ／ロード、`F10` 相場表、`X` 建物を半透明に、`F5` 町、`F7` 駅、`F8` 財務、`F12` 産業、`Shift+F1` 列車、`Delete` ウィンドウを閉じる。

## 開発

```sh
npm install
npm run dev       # 開発サーバー（スマホからは同じWi-Fiで表示されるURLへ）
npm test          # シミュレーションのテスト
npm run build     # 本番ビルド（dist/）
npm run build:test # 自動テスト用のビルド（window.__game・__debug を出す。公開しない）
```

URL に `?seed=12345` を付けると同じマップで遊べます。

### 構成

```
src/
  sim/       シミュレーション（描画と分離。テストあり）
    world.ts      世界の状態
    commands.ts   プレイヤーの操作（建設・列車・指令・元に戻す）
    simulate.ts   時間を進める（列車・生産・町・お金）
    economy.ts    運賃の計算
    market.ts     相場とブーム
    specialty.ts  名産品（工房・評判・観光客）
    company.ts    会社のランクと実績
    challenge.ts  チャレンジモード（ミッション・ステージ・今日／ランダム）
    towns.ts      町の段階と受け入れる貨物
    events.ts     イベント（火事）
    requests.ts   依頼ボード（まったりミッション）
    save.ts       セーブデータの形式（版番号つき）
    validate.ts   セーブの読み込み時の検査（形・種類・範囲）
    track.ts      経路探索・ドラッグの形
    mapgen.ts     マップ生成
  render/    PixiJS による斜め見下ろしの描画
  input/     入力変換レイヤー（マウス・タッチ → 操作の意味）
  ui/        ウィンドウ・パネル・アイコン・取扱説明書とリリースノート（manual.ts）
  version.ts ゲームの版（タイトル・ヘルプに表示）
  storage.ts セーブの保存先（IndexedDB）・ファイルの書き出し
  game.ts    まとめ役（ツール・プレビュー・キー操作・ループ・オートセーブ）
  data/      文章のデータ（zukan.md：車両図鑑の説明文。だれでも書き足せる）
tests/       Vitest
```
